# 审校采纳反馈的精确记录与并发保护

**目标：** 同任务并发反馈不互相覆盖，记录只对应作者采用的具体建议。

**设计：** 当前接口读整个 output 后无条件整份回写，且只匹配第一处 quote。本轮采用已完成 REVIEW 任务行锁，在锁内核对建议序号/原文/替换文/报告来源哈希与 verified，保持其他建议与输出字段；新反馈写 applied=true 与首次反馈时间/用户，重复反馈只返回不写。页面在同步采纳成功后发送捕获的任务与建议凭据，反馈仍是编辑器动作信号。

**取舍：** 仅按 quote 无法消除同引用多建议歧义；全 JSON CAS 需重试与更多往返。现有任务行锁即可序列化短事务，无新表/schema。接口不根据当前章稿推断已经持久保存，不实现跨刷新反馈队列或模型语义采纳评估。
