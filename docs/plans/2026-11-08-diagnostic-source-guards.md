# 四类章节诊断可信度与来源保护

**目标：** 有效诊断才显示参考评分，报告绑定整章正文，过期/取消/旧轮次不发布有效结果。

**现状：** handler截取前8000字，无效输出仍成功并补零分，缺少来源与终态保护；时间线无当前章/稿校验。使用既有审校/DESLOP保护模式，保持四类任务类型及性能摘要。

**方案：** 完整正文最多20000 Unicode字符，超限调用前明确失败。严格JSON、0至100整数及风险枚举/问题/建议字段，非法报告原子FAILED，不造评分。预检组织/项目/类型/RUNNING/attempt；锁章→锁对应类型任务后核对全文/终态/轮次，step+报告或拒绝原子提交；usage记录可得响应，最终step凭证保护确认丢失。输出chapterId/sourceSha256/sourceChars。页面异步核全文hash，来源变更/切章/旧任务/卸载丢弃；发起前flush并核对等待期间改文，不在只读诊断成功后刷新正文。

**取舍与边界：** 拒绝超限比静默截断或新增分段模型流水线更明确；严格失败比用零分表达结构异常更可信。评分是模型建议，不证明真实读者行为。正文哈希不检测ABA，作品设定/标题等提示上下文是请求时快照，不承诺跨设置变化自动重新诊断。
