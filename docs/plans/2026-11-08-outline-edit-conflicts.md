# 手动大纲编辑冲突保护

**目标：** 旧页面不能覆盖或删除其他页面刚更新的大纲，冲突保留本地表单并允许明确核对处理。

**设计：** GET列表/单项与创建/更新返回revisionHash，取节点身份、归属、层级、标题、摘要、顺序、状态及绑定章的确定性SHA256。PATCH/DELETE要求baseRevisionHash，项目锁内重读节点再比较；过期异稿409无写入，同目标更新无写入确认。单项读取保持组织/未删项目范围。页面编辑捕获基线，409保留表单，先读取最新节点展示，再明确采用远端或保留当前本地并保存；读取失败和等待期间改文不会隐式丢稿。

**边界：** 指纹不检测ABA，未引入schema/revision计数或自动合并。删除只保护目标节点，原层级处理政策不扩展；验收删除限全回滚合成夹具/拦截请求，不删除真实或持久记录。保存确认丢失同内容可重试，表单草稿不新增跨刷新存储。
