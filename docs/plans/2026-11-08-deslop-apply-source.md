# 去 AI 味扫描建议应用保护

**目标：** 规则扫描只可应用到同章同一全文，先保存当前作者稿，冲突和迟到响应不覆盖新稿。

**方案：** 扫描捕获 project/chapter/content，在任何 await 后核对来源与请求代际。编辑使报告/待确认失效，应用校验原范围实际匹配后 flush，再次核对后发送原全文哈希。组件按章节重挂且卸载淘汰旧响应。服务保留锁章 CAS 与原子快照/记忆维护，合法基线必需且大小写兼容；当前已为目标则无写入确认，支持丢回执重试。

**取舍：** 只校验命中文字不能保护旧位置与选区外改文；直接应用到编辑器会改变既有服务端版本链。本轮复用原服务写入与正常 reload 的 dirty 冲突保护，不增加 schema 或模型调用。哈希 ABA 与跨刷新持久凭证仍不覆盖。
