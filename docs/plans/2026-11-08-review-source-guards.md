# 审校报告与采纳来源保护

**目标：** 审校结果可核对其整章来源，作者只能向同章同稿采纳唯一可定位的引用。

**证据与设计：** 原页面以 indexOf 取第一次引用且不核全文，旧/跨章报告可误用于当前正文。原 worker 截断 12000 字、无效 JSON 仍通过、无任务终态/来源锁。采用现有 DESLOP/改写模式：worker 完整输入有限上限、严格结构、输出 chapterId/sourceSha256/sourceChars，唯一逐字引用可采纳；锁章→锁任务校验来源/attempt/RUNNING，step+report 原子完成。响应用量如实记录，确认丢失读取成功凭证，不降级已完成 step。页面核对异步哈希与章节/全文后才展示可采纳报告，编辑失效，重复引用不猜位置，采纳仅入编辑器并沿现有 CAS 保存。发起前 flush 期间改文不提交。

**取舍：** 只查引用存在无法保护上下文或重复位置；本轮保守采纳一项后重审，不自动重定位余项。拒绝超限而非静默截断，不做新分段模型流水线。采纳反馈是编辑动作信号，不承诺持久保存；反馈并发治理不扩展。
