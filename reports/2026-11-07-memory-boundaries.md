## 原始证据与修复

1. 原 activeMemorySourceFilter 只核对来源租户、项目和未删除状态。实际预览模块的合成委托复现生成第2章时同时含第1章事实、第2章旧稿摘要、第3章揭晓内容。共享过滤新增 chapterNo < currentChapterNo，两个调用端传入当前章号；不依赖记忆 contentJson 中可能过时的编号。
2. 原 buildExtractPrompt 使用 content.slice(0,8000)，尾部事件不可见但抽取仍可能标成功。删除静默截断，按 Unicode codepoint 验证上限；独立任务超限直接 FAILED / MEMORY_SOURCE_TOO_LONG，批量共用核心在请求前抛出明确错误。不会自动拆分或增加付费调用。
3. 独立审查确认批量抽取原先只 console.warn，用户无具体原因。本轮复用已有 generationWarnings 展示，超限提示拆章，其他失败提示检查设置/正文后重抽；不向页面传原始供应商异常。
4. 记忆面板说明前置章节摘要会自动纳入，以及完整输入和单次上限。accepted仍代表可使用状态，不能代替人工语义核对。
